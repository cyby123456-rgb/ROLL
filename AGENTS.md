# Agent Instructions

Before working in this repository, read `codex.md` for the current debugging
state, verified findings, pending fixes, and user-owned worktree changes.

After each debugging session, update `codex.md` with:

- the exact error and relevant dependency versions;
- the confirmed cause;
- commands or code changes used to fix it;
- verification results and the next pending step.

Do not mark a suggested fix as complete until its result has been observed. Do
not revert or overwrite unrelated user changes in the dirty worktree.
